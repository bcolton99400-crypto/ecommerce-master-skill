# Medical Topical E-commerce Skill

适用于医药/医疗健康电商中的：药膏、软膏、乳膏、凝胶、喷剂、贴膏、贴剂及类似外用产品。

## 使用方式

在 ChatGPT/Codex 中明确要求：

> 使用 medical-topical-ecommerce-skill，制作这个产品的淘宝/天猫详情页。

或：

> 启动医药外用详情页模式。

## 核心原则

**监管/证据真实性 > 产品真实性 > 消费者理解 > 视觉证明 > 美观。**

这套 Skill 不会根据产品类别自行补充疗效、治疗、临床、认证或医生背书等信息。所有高风险医疗声明必须来自用户提供的可靠产品资料，并保持原意，不夸大。

## 默认输出

5 张主图 + 10 屏详情页：

- H01 产品/品类识别
- H02 核心有依据卖点
- H03 正确使用
- H04 剂型/材质/包装功能证明
- H05 目标用户场景与信任
- D01-D10 从产品认知、使用、事实证明、规格、注意事项、信任到收口

## 与家具 Skill 的关系

它与 `ecommerce-master-skill` 共享商业策略、Visual DNA、Picture Solo、5+10、Prompt 和 QA 的方法论，但使用独立的医疗/健康合规规则，避免把家具类规则直接套到医药产品上。
