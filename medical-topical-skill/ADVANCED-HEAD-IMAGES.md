# 医药外用电商高级主图 Skill

## 1. 定位

本 Skill 专门负责药膏、软膏、乳膏、凝胶、喷剂、贴膏、贴剂等外用医疗/健康产品的**高级电商主图**，不是普通白底产品图，也不是简单把产品放大加标题。

目标是同时做到：

**3秒识别产品 + 1个核心卖点 + 1个可见证明 + 高级商业视觉 + 产品包装准确 + 医疗表达克制。**

默认生成一套 5 张主图，并可根据平台要求调整数量与比例。

## 2. 输入优先级

### 必需
- 产品包装/实物图，建议 2–6 张
- 正面包装图至少 1 张

### 强烈建议
- 背面/侧面包装
- 喷头、软管、贴膏等结构细节
- 产品使用说明
- 注册/备案/批准资料（如适用）
- 官方卖点与适用信息
- 目标平台
- 视觉参考图

### 产品图角色
- P01：正面主产品 Truth Anchor
- P02：侧面/背面结构
- P03：45°立体形态
- P04：局部材质/结构
- P05：包装组合/规格
- P06：真实使用状态（如有）

如果输入不足，禁止自行补造包装、容量、成分、医学身份或疗效。

## 3. 主图战略

默认 5 张：

### H01｜品牌/产品第一记忆
目的：一眼知道卖的是什么。

画面：产品为绝对视觉主角；包装文字尽量真实；背景建立品类高级感；核心标题只表达已确认事实或合规卖点。

### H02｜核心差异点
目的：让消费者知道为什么值得点击。

用一个明确的产品差异点作为视觉中心，例如剂型、使用方式、规格、材质或官方资料支持的卖点。

禁止把“舒缓/治疗/消炎/杀菌/修复”等词自动升级为产品疗效。

### H03｜使用方式证明
目的：把“怎么用”变成一眼可理解的画面。

药膏/软膏/乳膏：合理表现取用、涂抹动作；
喷剂：合理表现喷头、喷雾方向与距离，但不虚构治疗效果；
贴膏：合理表现撕膜、贴敷、服帖等物理动作；
凝胶：可表现质地与涂抹动作，但不能通过视觉暗示治疗结果。

### H04｜产品结构/材质/参数证明
目的：让消费者看到“产品本身有什么”。

可用包装局部、喷头、管口、贴膏结构、材质、容量/数量等真实信息进行高级特写。

### H05｜目标人群/生活场景
目的：建立购买代入感。

只表现真实、自然、合理的使用环境或生活状态；不通过痛苦表情、严重病变或 Before/After 暗示疗效。

## 4. 高级视觉系统

默认视觉方向：
- premium healthcare e-commerce
- clean clinical + lifestyle hybrid
- controlled studio lighting
- realistic product photography
- refined material rendering
- generous negative space
- clear information hierarchy
- restrained medical cues
- high-end marketplace advertising

避免：廉价医疗蓝、医院模板、满屏十字、假医生、假实验室、伪科研背景、夸张人体器官、血腥病灶、低俗痛苦表情。

## 5. 高级主图构图规则

### 产品占比
H01：约 35–65%，根据包装形态调整；
H02：产品 + 卖点视觉证明；
H03：人物/手部可占更大比例，但产品必须清楚；
H04：局部特写可以让产品细节成为画面主体；
H05：产品可以缩小，但必须仍然可识别。

不要五张都把产品放在画面正中央。

### 构图多样性
5 张主图至少 4 种 Main Visual：
1. hero product composition
2. use-action composition
3. macro/detail composition
4. structured information composition
5. lifestyle composition

## 6. 视觉证明 Pattern Library

### Pattern A｜Hero + single proof
产品英雄图 + 一个真实可验证卖点。

### Pattern B｜Action proof
真实使用动作证明使用方式。

### Pattern C｜Macro proof
喷头、管口、贴膏表面、质地、包装细节等局部特写。

### Pattern D｜Material/Form proof
剂型、物理形态、包装材料或结构特写。

### Pattern E｜Scale/quantity proof
容量、数量、尺寸或包装组合，以事实表达。

### Pattern F｜Scenario proof
合理使用场景，不制造疗效暗示。

### Pattern G｜Instruction proof
简洁展示正确使用步骤，仅使用官方/用户提供的信息。

禁止用装饰图标代替上述视觉证明。

## 7. 医疗合规主图规则

所有主图先通过 Claim Lock。

### 可以优先使用
- 产品名称
- 剂型
- 容量/数量
- 使用方式
- 包装明确文字
- 官方资料明确支持的产品特点
- 合规注册/备案信息（必须真实）

### 必须有依据才能使用
- 治疗疾病
- 缓解特定症状
- 消炎/杀菌/抗病毒
- 临床验证
- 有效率
- 医生推荐
- 医院同款
- 国家认证
- 特殊机制
- 快速见效
- 安全无副作用

### 默认禁止
- 根治
- 药到病除
- 100%有效
- 永久解决
- 零副作用
- 替代医生/药物/治疗
- 虚假前后对比
- 虚构医学实验
- 虚构权威背书

## 8. 产品包装锁

生成前建立 Product Identity Lock：

**产品名称 / 品牌 / 剂型 / 净含量 / 数量 / 包装颜色 / 瓶管盒形状 / 喷头 / 贴膏轮廓 / 标签布局 / 文字 / logo / 结构比例。**

生成时禁止：
- 改品牌
- 改包装颜色
- 改容量
- 改文字
- 改剂型
- 改喷头结构
- 改贴膏形状
- 添加不存在的包装
- 删除关键包装信息

## 9. 参考图使用

参考图只提取：
- 高级感
- 光线
- 构图骨架
- 色彩关系
- 字体气质
- 信息密度
- 商业广告语言

禁止直接复制：
- 其他品牌包装
- logo
- 医生形象
- 认证徽章
- 医院场景
- 他人医学声明
- 他人广告文案

## 10. 文案规则

主图每张只解决一个问题。

优先结构：
**消费者结果/理解点 → 产品事实 → 必要限定。**

避免：
“专业品质、匠心制造、值得信赖、效果看得见”等空泛语言。

所有文字必须短、清晰、可读；不要让复杂医学知识成为主图阅读负担。

## 11. 图片中的文字

如果需要生成文字，Prompt 必须明确：
- 精确文字
- 字体气质
- 字号层级
- 位置
- 安全边距
- 不得错字

对药品/医疗产品包装上的原有文字，优先保持真实，不重新设计。

## 12. Picture Solo Test

每张主图必须满足：

> 隐藏所有文字后，消费者只看图片 2 秒，仍然能够理解这张图主要在证明什么。

如果无法做到，重新选择视觉 Pattern。

## 13. 主图 Prompt Contract

每张 Prompt 必须包含：
1. 主图目标
2. 产品 Identity Lock
3. 核心信息
4. Picture Solo Statement
5. Proof Pattern
6. 产品占比
7. 主视觉
8. 场景
9. 构图
10. 镜头/视角
11. 灯光
12. 材质
13. 人物动作（如有）
14. 合规文案
15. 参考图 DNA
16. 比例
17. Negative Constraints

## 14. QA

### 产品 QA
包装、品牌、剂型、容量、数量、颜色、结构、喷头/管口/贴膏形状准确。

### 文案 QA
没有未经证实的疗效、认证、临床、医生背书、比较或保证性承诺。

### 视觉 QA
无假医院权威、假实验室、虚假医学机制、夸张病灶、虚假 Before/After。

### 商业 QA
3秒识别；信息层级清晰；每张主图只解决一个主要问题；至少4/5 Main Visual 不同；没有图标堆砌。

## 15. 默认输出

收到产品图后，先输出：

**A. 产品 Truth Lock**
**B. Claim Lock**
**C. 目标消费者**
**D. 5张高级主图策略表**
**E. 每张 Picture Solo Statement**
**F. 每张视觉 Prompt**
**G. Negative Constraints**
**H. QA Checklist**

默认不直接假设疗效或医疗身份；资料不足时采用最保守的可见事实表达。
