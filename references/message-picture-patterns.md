# Message-to-Picture Patterns

Use the matching picture pattern before writing a prompt. Adapt the pattern to the actual product; do not copy literally.

| Message | Picture pattern | Product presence |
|---|---|---|
| Multi-variant | Actual variants arranged clearly | none/full packaging not required |
| Natural/simple | Raw ingredients/material source still life | usually none |
| Soft/material feel | Macro texture + natural touch/contact | none |
| Micro detail | Extreme macro of relevant structure/finish | none |
| Mechanism/technology | Cutaway, exploded view, structure or path | partial/mechanism-led |
| Scene-fit/lifestyle | Real-feel user scene | small/medium/none |
| Operation | Actual hand/action moment | medium/partial |
| Sensory/result | Visible result/body moment/texture | none |
| Parameter/spec | Scale reference, measurement lines, clean factual layout | partial |
| Trust/quality | Inspection/craft/testing moment | variable |
| Closing set | Product family still life | full product |
| Audience persona | 2-4 real-feel mini-scenes | variable |

## Hard rule
If a screen is defaulting to "product hero centered", stop and match its message to a pattern first. A single screen may combine at most two patterns when genuinely necessary. If a pattern requires no packaging, do not add packaging merely for recognition.
