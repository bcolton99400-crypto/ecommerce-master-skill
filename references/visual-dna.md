# Visual DNA

## Set-level contract
Extract and lock:
- commercial genre
- color relationship and contrast
- typography attitude
- layout rhythm
- light/material world
- camera language
- graphic language
- emotional temperature

State: must carry / may vary / must not copy / scatter risks.

## Consistency without sameness
Share product/brand color system, typography hierarchy, light/material world, commercial temperature and a small set of recurring design language. Vary proof method, composition, camera distance, people, information density, product scale/crop and scene/macro/mechanism/parameter treatment.

## Reference weight
- H01: strongest when a clear first-head reference exists; otherwise medium-high mood transfer.
- H02-H04: medium; selling point and proof method override layout.
- H05: medium; audience logic leads.
- D01: medium-high campaign memory.
- D02/D06: medium mood and typography; real use overrides pose.
- D03-D05: medium-low; proof grammar leads.
- D07/D08: low-medium; clarity leads.
- D09/D10: medium for trust and brand memory.

Each output must state 2-4 DNA elements carried. Avoid repeating the same scene, subject and composition.

## Diversity hard gate
- 5 head images: at least 4 distinct main visuals.
- 10 detail screens: at least 7 distinct main visuals.
Main visual = scene + main subject + composition family.

Before prompts, produce a diversity board with output, message, pattern, scene, subject, composition and product presence. If thresholds fail, re-plan rather than merely rewriting prompts.
