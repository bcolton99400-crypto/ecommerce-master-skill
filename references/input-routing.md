# Input Routing

## Purpose
Route every task according to how much reliable product information is available. Never fill missing facts with invented specifications.

## Routes

### Complete
User supplies product facts, selling points, parameters, target audience, platform, and/or documents.
- Treat supplied facts as source of truth.
- Preserve exact parameters where precision matters.
- Translate technical facts into buyer benefits without changing meaning.
- Use risk claims only when evidence is supplied.

### Partial
User supplies scattered facts or notes.
- Preserve supplied facts.
- Improve wording into consumer language.
- Infer only visible/product-category-generic points.
- Mark inferred points as inferred.
- Do not invent numeric, certification, medical, official, or performance claims.

### Image-only
Only product/reference images are supplied.
- Infer category, visible features, plausible scenes, and buyer concerns conservatively.
- Use soft category-generic language.
- Never invent specifications, ratings, certifications, prices, test results, or performance.
- If the user has not explicitly asked to skip questions, ask once whether additional product facts, selling points, parameters, brand colors, or documents are available. Do not repeatedly block progress.

## Fixed screen directions
If the user supplies or approves a page/screen structure, preserve it as hard scaffolding. Improve the expression and proof inside each screen rather than replacing the structure with a generic template.

## Selling-point bank
Create this before image planning:

| Point | Source | Safety | Buyer meaning | Best proof |
|---|---|---|---|---|
| ... | user/document/visible/inferred | safe/risky/unsupported | why buyer cares | scene/macro/mechanism/comparison/parameter/trust |

## Consumer-angle map
For each point or fixed screen direction define:
- buyer anxiety/desire
- consumer-facing promise
- evidence moment
- safe wording boundary

## Document extraction
Separate uploaded material into:
- hard facts
- priority messages
- expression candidates
- risk claims needing evidence
- brand assets and mandatory identity rules

Never alter hard facts. Rewrite expression candidates only for clarity and conversion.
