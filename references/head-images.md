# Head Images

## Default 5-image system
| Image | Role | Core job |
|---|---|---|
| H01 | Main/click | Product recognition + strongest buying reason |
| H02 | Selling point A | Prove quality/source/material/core feature |
| H03 | Selling point B | Prove mechanism/performance/comparison when supported |
| H04 | Selling point C | Prove usage/detail/practical value |
| H05 | Audience/persona | Help target users recognize themselves |

## Hard gates
- At least 4 of 5 main visuals must be distinct.
- H02-H04 must use different proof patterns.
- Reference scene elements: max 1 of 5 unless user explicitly scene-locks the set.
- H01 may follow a clear first-head reference's layout skeleton; replace its product, copy, claims, brand and incompatible colors.
- H02-H05 must not become the same centered-product template.

## Prompt requirements
Every head-image prompt must specify 1:1 square, Picture Solo Statement, consumer-voice copy, pattern/proof form, product exposure, adapted palette, reference DNA, model consistency when applicable, and anti-icon constraints.
