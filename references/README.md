# Reference Library

The master skill is intentionally modular. `SKILL.md` is the orchestration layer; these files are specialized decision libraries.

- `input-routing.md` — information completeness and source-of-truth routing
- `reference-analysis.md` — reference roles, transfer rules, model/use plausibility
- `visual-dna.md` — campaign consistency and diversity gates
- `color-adaptation.md` — product-first palette adaptation
- `visual-proof-grammar.md` — Picture Solo, consumer voice, product exposure, no-icon rule
- `message-picture-patterns.md` — reusable message-to-picture patterns
- `head-images.md` — 5-image marketplace system
- `detail-pages.md` — 10-screen detail-page system
- `production-loop.md` — generation and QA loop
- `furniture-product-lock.md` — furniture/structured-product accuracy
- `compliance-rules.md` — claim-safety baseline
