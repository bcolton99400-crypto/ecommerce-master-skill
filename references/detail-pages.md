# Detail Pages

## Default 10-screen narrative
| Screen | Role | Typical expression |
|---|---|---|
| D01 | Hero | Core promise + product memory |
| D02 | Pain/scene | Real user situation |
| D03 | Selling A | Material/source/technical explanation |
| D04 | Selling B | Mechanism/comparison/proof |
| D05 | Selling C | Experience/sensory benefit |
| D06 | Usage | Real use scene |
| D07 | Practical | Capacity/portability/operation/storage etc. |
| D08 | Detail | Craft/material/parameter/structure |
| D09 | Trust | Factual quality/service basis |
| D10 | Closing | Product set + final buying reason |

If the user provides an existing screen structure, preserve it.

## Hard gates
- Strict 3:4 vertical for detail pages.
- At least 7 of 10 main visuals must be distinct.
- No single reference-scene element in more than 3 of 10 outputs unless explicitly scene-locked.
- At least 4 of 10 screens should use no packaging or partial product exposure.
- Detail pages must not be vertical copies of H01.
- Every screen passes Picture Solo Test and consumer-voice test.
- No icons/pictograms/badge ribbons/feature-icon rows.

## Prompt requirements
Each prompt must include strict 3:4, one independent final screen, Picture Solo Statement, consumer-facing copy, chosen pattern/proof form, product exposure, density, adapted color palette, reference DNA, model lock if applicable, scene-cap note, and anti-icon constraints.
