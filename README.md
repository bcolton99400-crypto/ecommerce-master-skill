# Ecommerce Master Skill

A unified skill for e-commerce commercial strategy and visual production.

## What it combines

- Commercial copywriting and conversion strategy
- Campaign Style Lock
- Reference-image / Visual DNA analysis
- Consumer-angle visual planning
- 5-image hero/main-image system
- 10-module detail-page system
- Production-ready image prompts
- Product-fidelity and claim-safety QA
- Furniture-specific structural and perspective locks

## Recommended usage

Provide:
1. Product images
2. Reference/competitor images
3. Product specifications
4. Target marketplace/platform
5. Known selling points and required claims

Then run the workflow:

**Product Truth → Commercial Strategy → Campaign Style → Visual DNA → Unified 5+10 Storyboard → Approval → Prompt → Production → QA**

## Design philosophy

The skill treats the commercial strategy layer as the source of *what to communicate* and the visual layer as the source of *how to prove it visually*. The two are intentionally coordinated through one approval gate.

For furniture, product accuracy takes priority over scene aesthetics.
